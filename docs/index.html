This fork publishes the TV flavour only — there is no phone APK here. Every build needs Android 5.1 / Fire OS 5 (API 22) or newer, and the app installs as Anilili.

Quick Setup

  1. 1 Open the latest release on the TV, or download it elsewhere and transfer the APK.
  2. 2 On Fire TV, open the Downloader app and enter the release URL. On Android TV, use adb install or a file manager.
  3. 3 Allow installs from unknown sources when Android asks, then install and open Anilili.
  4. 4 Updates arrive through the app itself: Settings → Check for updates picks up every release from this repository.

AnimeX is a personal, educational fork of Anilili, released under the MIT No Attribution license. It hosts no content: all streams are resolved dynamically from public third-party services at playback time. Not affiliated with AniList, MyAnimeList, or any streaming provider. The app installs as Anilili and updates from this repository's releases.
